## Règle de l'utilisateur : aucun frais (22 octobre 2026)

« Je ne veux pas payer aucun autre frais que mon abonnement sur Claude. » **Ne jamais proposer ni mettre en place un service payant** (plan payant d'hébergeur, API facturée à l'usage, abonnement) : rester sur les plans gratuits (Netlify, Cloudflare, Supabase, Brevo, Zeffy, Google) et les outils qui tournent dans le navigateur. **L'abonnement Claude ne couvre pas l'API Anthropic** : toute fonction qui appelle `ANTHROPIC_API_KEY` (`coach.mts` : Analyse tactique, Stats auto, devoirs, commentateur du Mode direct, IA de la Retouche photo) serait facturée à part. Tant que l'utilisateur ne l'a pas explicitement accepté, ces fonctions restent sans clé (elles affichent un message clair) et il faut proposer des solutions gratuites (étape manuelle via une conversation claude.ai, ou modèle qui tourne sur l'appareil). **IA gratuites (22 octobre 2026, choix de l'utilisateur : « Gemini comme IA principale, et Workers AI en secours automatique »)** : sans `ANTHROPIC_API_KEY`, toutes les fonctions IA de `coach.mts` (Analyse tactique et suivi, Stats auto, devoirs, commentateur du Mode direct, Retouche photo) passent par `art-craft/netlify/lib/free-ai.ts` (rangé hors de `netlify/functions/` pour que Netlify n'en fasse pas une fonction) :
  - **Google Gemini, plan gratuit** : clé `GEMINI_API_KEY` créée par l'utilisateur sur aistudio.google.com (sans carte), ajoutée comme secret Cloudflare (jamais dans le chat). API REST `generateContent`, en-tête `x-goog-api-key`, sortie JSON via `generationConfig.responseFormat.text` (`mimeType: APPLICATION_JSON`, `schema`) ; si Gemini refuse le schéma (400, trop complexe), on renvoie la demande avec le schéma dans la consigne. Modèles : `gemini-3.8-flash` (`GEMINI_MODEL`), `gemini-3.1-flash-lite` pour le commentaire en direct. Limites : quota quotidien (que Google a déjà réduit plusieurs fois) ; sur le plan gratuit, Google peut utiliser les données envoyées pour améliorer ses produits (dit à l'utilisateur).
  - **Secours automatique : Cloudflare Workers AI** (liaison `[ai] binding = "AI"` dans le `wrangler.toml` racine, passée à `handleCoach(req, env, ai)` par `worker/index.ts`), modèle `@cf/meta/llama-4-scout-17b-16e-instruct` (vision, images en `image_url` base64, 8 images au plus, `response_format` `json_schema`). Utilisé si Gemini répond 429 (quota) ou 5xx, ou si `GEMINI_API_KEY` manque. 10 000 neurones gratuits par jour ; le plan gratuit Workers ne facture jamais (les appels s'arrêtent au quota). Moins bon que Gemini pour lire le jeu.
  - **2e secours : OpenRouter, modèles gratuits seulement (27 octobre 2026, l'utilisateur a une clé OpenRouter et a ajouté le secret Cloudflare `OPENROUTER_API_KEY` au Worker `coachyass`)** : ordre Gemini → OpenRouter → Workers AI. `askOpenRouter` (`free-ai.ts`) envoie la demande au format OpenAI (`/api/v1/chat/completions`, images en `image_url` base64, `response_format` `json_schema` ; si refusé (400), réessai avec le schéma dans la consigne) avec `models` = `nvidia/nemotron-3.5-super-vl:free`, `google/gemma-4-31b-it:free`, `openrouter/free` (tous gratuits et lisent les images, OpenRouter passe au suivant tout seul). Garde-fou `isFreeModel` : seuls les modèles `:free` ou `openrouter/free` sont envoyés. **Ne jamais acheter de crédits OpenRouter** (avec 0 $ de crédit rien n'est facturable ; quota gratuit limité par jour). Toute erreur d'OpenRouter (quota, clé refusée, panne) passe à Workers AI. Pas pour les liens YouTube (Gemini seul). `ping` renvoie `openrouter` si c'est la meilleure IA branchée. **Diagnostic** : ouvrir `https://coachyass.moqtad6.workers.dev/api/coach?test` (GET) pose « Dis OK » à chaque IA séparément (`testFree`) et affiche OK / erreur pour Gemini, OpenRouter et Workers AI, sans montrer les clés. Testé avec les IA simulées + `wrangler deploy --dry-run`, puis **en ligne le 27 octobre 2026** (PR #100 fusionnée) : `?test` → Gemini OK (1,6 s), OpenRouter OK (`nemotron-3.5-super-vl:free`, 0,9 s), Workers AI OK (0,3 s).
  - **3e secours : Groq (27 octobre 2026, demande « Mettre » après la comparaison des outils gratuits)** : ordre **Gemini → OpenRouter → Groq → Workers AI**. `askGroq` (`free-ai.ts`) : clé gratuite `GROQ_API_KEY` (console.groq.com, sans carte), modèles essayés dans l'ordre `GROQ_MODELS` = `qwen/qwen3.8-27b`, `qwen/qwen3.6-27b` (Llama 4 Scout a été **retiré par Groq le 17 juillet 2026** : erreur « model does not exist » vue le 27 octobre ; un modèle retiré ou inconnu passe au suivant ; secret facultatif `GROQ_MODEL` pour en imposer un autre en tête de liste), API OpenAI `chat/completions`, **5 images au plus** par demande (limite de Groq, `thinImages`), schéma JSON dans la consigne. Toute erreur de Groq passe à Workers AI. Le diagnostic `?test` affiche aussi `groq` (il ne pose qu'une question texte : il vérifie la clé et le modèle, pas la lecture d'images). Clé de l'utilisateur vérifiée le 27 octobre (Groq répond, seul le modèle était à changer). La page `?test` est servie en `charset=utf-8` (accents corrects sur iPhone). Écartés après comparaison : Mistral gratuit (données utilisées pour l'entraînement, téléphone, ~2 demandes/min), GitHub Models (fermeture annoncée en 2026), NVIDIA NIM (téléphone, plutôt un essai). Jamais de clé trouvée dans un dépôt public : seulement des clés créées par l'utilisateur. Testé avec des API simulées.
  - La réponse garde le flux NDJSON des pages (`{wait}` tout de suite, puis `{d}` en un morceau et `{end}`) ; le JSON est vérifié avant envoi. `ping` renvoie `provider` (`claude`, `gemini`, `workers-ai` ou `null`).
  - **Analyse d'un lien YouTube (23 octobre 2026, demande « un outil open source pour déposer un lien YouTube et analyser la vidéo de basketball », puis « adopte les meilleures options pour moi »)** : les outils open source repérés (abdullahtarek/basketball_analysis, AI-Basketball-Shot-Detector, SwishAI) tournent en Python sur ordinateur, ne prennent pas de lien YouTube et reposent sur YOLO d'Ultralytics (AGPL) : idées seulement, pas de code repris. Choisi à la place : **Gemini regarde lui-même une vidéo YouTube publique** (gratuit, 8 h de vidéo YouTube par jour au plus ; pas les vidéos « non répertoriées » ni privées ; ~1 image/s). Dans l'Analyse tactique, champ « … ou colle un lien YouTube » (`yt-form`, lecteur `youtube-nocookie` intégré) : la page envoie `{ youtube, start, dur, team, context }` sans images ; `coach.mts` (`youtubeUrl` : watch, youtu.be, shorts, live → adresse « watch » normalisée, tout autre hôte refusé) met un bloc `youtube` que `free-ai.ts` traduit en `fileData.fileUri` + `videoMetadata` (`startOffset`/`endOffset`) ; les instants demandés sont ceux de la vidéo entière. Toujours par Gemini, même si `ANTHROPIC_API_KEY` existe ; pas de secours Workers AI (il ne lit pas YouTube). Résultat : rapport + moments clés (clic → lecteur YouTube 3 s avant) ; ni suivi image par image ni vidéo commentée (il faut le fichier, et télécharger depuis YouTube est contraire à ses règles). Testé avec Gemini simulé et dans Chromium (390 px).
  - **Aucun mot de passe (23 octobre 2026, demande « je veux aucun mot de passe »)** : `ART_CRAFT_PASSWORD` est devenu **facultatif**. Sans lui, `coach.mts` laisse passer tout le monde (`ping` renvoie `open: true`) et les pages entrent directement : Analyse tactique et Stats auto sautent l'étape de connexion, le champ est caché dans le Mode direct et dans le Studio IA de la Retouche photo. Garde-fou : **sans mot de passe, `ANTHROPIC_API_KEY` est ignorée** (seules les IA gratuites Gemini/Workers AI servent), pour que personne ne puisse faire payer l'utilisateur. Contrepartie expliquée à l'utilisateur : n'importe qui qui trouve l'adresse peut consommer le quota gratuit du jour (rien n'est facturé). Si `ART_CRAFT_PASSWORD` est remis un jour, tout redevient protégé comme avant. La connexion au **compte admin du Dashboard** (envoi dans l'Espace Joueurs, publication Instagram) reste exigée : elle protège Supabase et n'est pas ce mot de passe-là.
  - **« Analyse impossible : Load failed » (23 octobre 2026, capture de l'utilisateur sur iPhone, Analyse tactique bloquée à « 0 caractères »)** : la connexion était coupée pendant que Gemini réfléchissait. Safari coupe une réponse restée muette 60 s, et c'est aussi ce qui arrive quand on change d'appli ou que l'écran se verrouille. Corrections :
    - `freeResponse` (`coach.mts`) envoie `{wait:true}` toutes les 10 s ;
    - les pages gardent l'écran allumé pendant l'analyse (`keepAwake`, Wake Lock, dans `common.js`) ;
    - la barre montre le temps écoulé (`waitLabel`, `readCoachStream`) ;
    - une connexion coupée (`isNetworkError`) relance un 2e essai automatique, plus léger (14 images au lieu de 24 pour l'analyse, 8 pour le suivi d'une action, `thinFrames`), puis affiche un message clair (`NETWORK_HINT`) ; même chose dans Stats auto ;
    - l'analyse envoie 24 images au plus (`MAX_FRAMES`, avant 32 ; ~0,6 Mo par envoi), plus léger en 4G et pour le Worker gratuit.
    - Testé : Chromium avec connexion coupée au 1er essai (relance réussie, analyse + suivi), puis coupée à chaque essai (message affiché) ; fonction avec un Gemini simulé qui met 25 s (signes de vie à 0, 10 et 20 s).
