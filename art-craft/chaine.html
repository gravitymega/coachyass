Relier ma chaîne YouTube

À configurer une fois (gratuit) :

  1. Console Google Cloud (même projet que Drive) : activer l'API YouTube Data v3.
  2. Identifiants → identifiant client OAuth « Application Web » : origine JavaScript https://coachyass.moqtad6.workers.dev, URI de redirection https://coachyass.moqtad6.workers.dev/api/chaine/callback.
  3. Écran de consentement : permission …/auth/youtube.force-ssl, puis « Publier l'application » (en mode « Test », Google coupe l'accès au bout de 7 jours).
  4. Cloudflare → Worker coachyass → Settings → Variables and Secrets : GOOGLE_CLIENT_ID et GOOGLE_CLIENT_SECRET (secret).
